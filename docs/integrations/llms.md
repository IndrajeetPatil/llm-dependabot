# LLM Integration

The llm-dependabot documentation is available in the
[llms.txt](https://llmstxt.org/) format.
This format is defined in Markdown and suited for large language models.

Two formats are available:

- [llms.txt](https://www.indrapatil.com/llm-dependabot/llms.txt): a file
  containing a brief description of the project, along with links to the
  different sections of the documentation. The structure of this file is
  described in detail in the
  [format documentation](https://llmstxt.org/#format).

- [llms-full.txt](https://www.indrapatil.com/llm-dependabot/llms-full.txt):
  like `llms.txt`, but with the content of every linked page included. This
  file may be too large for some LLMs.

Every page is also available as Markdown: append `index.md` to its address,
for example
[`setup/index.md`](https://www.indrapatil.com/llm-dependabot/setup/index.md).
